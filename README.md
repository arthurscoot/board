# Minha Codificação - Sistema de Board

Esta é a minha versão de codificação do sistema de board proposto pelo professor. Fiz algumas alterações na estrutura e funcionamento do projeto para melhor atender às minhas necessidades.

## Tecnologias Utilizadas

- **Flyway**: Utilizado para gerenciar e versionar o banco de dados de forma automática. O Flyway permite aplicar e versionar scripts de migração de forma incremental, o que facilita a manutenção do banco de dados ao longo do tempo.
